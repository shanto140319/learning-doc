NestJS is the most popular structured backend framework for Node.js, and it's in a large share of remote TypeScript job ads. It gives you what you built by hand in the [Node.js and HTTP](/docs/node-http) section (routing, body parsing, validation, error mapping, shutdown) plus a strong structure for big codebases: **modules and dependency injection**.

All examples build the **booking platform API**. By the end, you'll have rewritten your plain-Node practice project in NestJS, and you'll know exactly what each part of Nest replaces.

## Before you start

Finish at least Lessons 3, 5 and 6 of [Node.js and HTTP](/docs/node-http) first. NestJS makes much more sense when you know what it does for you. Also read [TypeScript best practices for NestJS](/docs/typescript/best-practices/nestjs); this section builds on it.

## Setup

You need Node.js 22+ and the Nest CLI:

```powershell
npm i -g @nestjs/cli
nest new booking-api --strict --package-manager npm
cd booking-api
npm run start:dev
```

Open http://localhost:3000. You should see "Hello World!". `--strict` turns on TypeScript strict mode; add `"noUncheckedIndexedAccess": true` to `tsconfig.json` yourself.
