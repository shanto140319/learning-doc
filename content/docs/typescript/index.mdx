## Setup (15 minutes)

1. Create a folder `ts-practice`, run `npm init -y` and `npm i -D typescript tsx zod`.
2. Run `npx tsc --init`, then set `"strict": true` and `"noUncheckedIndexedAccess": true` in `tsconfig.json`.
3. Create one file per lesson (`lesson1.ts`, `lesson2.ts`…). Run `npx tsc --noEmit` to type-check and `npx tsx lesson1.ts` to run.

## How each lesson works

1. Read the lesson and type the examples yourself. Don't copy-paste; typing builds memory.
2. Do the exercises without AI help first. Getting stuck for 10 minutes is part of learning.
3. Paste your answers into Claude for a review, an honest score and extra practice where you're weak.
4. Only then check the [Solutions](/docs/typescript/solutions) page.
5. After each lesson, ask for a quiz. Five quick questions locks it in.

## The example domain

Most examples use these booking-platform types:

```typescript
type Service = {
  id: string;
  name: string;                       // "Haircut", "Consultation"
  location: 'in_person' | 'online';
  durationMinutes: number;
  createdAt: Date;
};

type Booking = {
  id: string;
  serviceId: string;
  customerEmail: string;
  startsAt: Date;
};
```
